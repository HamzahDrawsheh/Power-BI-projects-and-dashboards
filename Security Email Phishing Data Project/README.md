## Overview
This project presents a **Power BI dashboard** built on the **Enron Dataset** for **Security Analysis** purposes. The dashboard provides an interactive way to explore email communications within the Enron organization, helping identify patterns, relationships, and potential security risks.

## Dataset Description
The **Enron Dataset** contains a large collection of real emails exchanged between Enron employees. Key aspects of the dataset include:

- **Sender and Receiver**: Email addresses of the sender and recipients, allowing analysis of communication flows.
- **Subject and Content**: Email subject lines and body text, useful for identifying topics and detecting sensitive content.
- **Timestamp**: Date and time when the email was sent, enabling timeline analysis and activity tracking.
- **Metadata**: Additional information such as CC/BCC fields, attachments, and email threads.

The dataset provides a rich resource for analyzing organizational communication, detecting anomalies, and understanding relationships between employees.

## Power BI Dashboard
The **Power BI dashboard** designed for this project includes the following features:

- **Communication Networks**: Interactive graphs showing the flow of emails between employees, highlighting frequent communicators and clusters.
- **Activity Over Time**: Line charts and heatmaps visualize email volume trends over days, months, or years.
- **Keyword Analysis**: Filters and visuals identify common keywords or sensitive terms appearing in emails.
- **Top Senders and Receivers**: Tables and charts highlight employees with the highest email activity.
- **Dynamic Filters and Slicers**: Users can explore the data by time period, employee, or email content for more detailed insights.

The dashboard allows security analysts to **monitor communication patterns**, detect unusual activity, and gain actionable insights from the Enron email dataset.

## Conclusion
This project demonstrates how the **Enron Dataset** can be leveraged for **Security Analysis** through an interactive **Power BI dashboard**. It provides a clear, visual, and user-friendly approach to exploring organizational email communications and identifying potential security concerns.
